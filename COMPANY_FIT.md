# Moledrop — Company and Team Fit

Matches are plausible skills fit, not claims that a company uses or endorses this project.

## Project thesis

A route-planning simulation for a made-up underground delivery network. It finds a low-travel-time path between hubs.

## Amazon Web Services

**Relevant technical areas:** Graph/data services and route optimisation.

**Potential roles:** Software Engineer, Data Engineer, Applied Scientist, Operations Research Engineer or Backend Engineer.

**Evidence to build:** Node.js graph prototype. Hub records and weighted tunnel links are loaded into an undirected graph; inactive hubs/routes are excluded; Dijkstra's algorithm selects a shortest-time route. It is a hypothetical simulation, not a live transport or robotics routing system.
